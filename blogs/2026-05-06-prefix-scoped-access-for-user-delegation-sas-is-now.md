We would like to share that prefix-scoped access for User Delegation SAS for Azure Blob Storage is generally available in all Azure regions . SAS tokens for Blob Storage have historically supported two levels of scope: container and individual blob. With this release, you can now scope access to a prefix or virtual directory within a container, granting access to all blobs beneath the path.
